# CEDCO BSF Bengaluru Cybersecurity Website

A responsive, professional static website starter for CEDCO BSF Bengaluru.

## Files
- index.html — main website
- styles.css — responsive design and styling
- script.js — mobile menu, year and demo contact form

## Important before publishing
Replace the placeholder contact email and phone number with officially approved details.
Add official logos, photographs, training schedules and approved institutional content as required.

## Run locally
Open `index.html` in a modern web browser.

## Publish
The folder can be uploaded to a static hosting service or institutional web server.
